# Code of conduct

## The short version

Be straight with people and assume they are being straight with you. Argue with
the work, not the person who did it. This project is largely about telling the
difference between what is measured and what is assumed — the same standard
applies to how we talk to each other.

## What is expected

- **Disagree with reasons.** "This is wrong because X" is welcome from anyone
  about anything here, including from a first-time contributor about a decision
  the maintainer made. "This is bad" is not an argument.
- **Say what you actually checked.** If you ran it, say so. If you are guessing,
  say that too. A guess labelled as a guess is useful; a guess presented as a
  measurement wastes someone's afternoon.
- **Take a correction plainly.** Being wrong in public is a normal part of
  engineering, not an injury.
- **Write for someone who is not you.** English is not everyone's first
  language, and neither is Arabic. Plain words beat clever ones.

## What is not

Harassment, insults, or demeaning comments. Personal or political attacks.
Publishing anyone's private information. Sexualised language or imagery, and
unwelcome attention of any kind. Sustained disruption of a discussion.
Encouraging any of the above.

This applies in issues, pull requests, commits, code comments and anywhere else
someone is representing this project.

## Reporting

If someone's behaviour here is a problem, tell the maintainers. The fastest
route is to open an issue if the matter is already public, or to contact a
maintainer directly through their GitHub profile if it is not. GitHub's own
[report abuse](https://github.com/contact/report-abuse) form is always
available and reaches GitHub regardless of what the maintainers do.

Reports are read and answered. You will not be asked to justify being
uncomfortable, and reporting something in good faith will never count against
you — including when the maintainer is the one being reported.

## Enforcement

The maintainers decide what happens, in proportion to what occurred:

1. **A private word**, for something that reads worse than it was meant.
2. **A public correction**, where the behaviour was public and others saw it.
3. **A temporary block** from interacting with the project.
4. **A permanent ban**, for sustained or severe behaviour.

A decision comes with the reason for it. If you think one was wrong, say so —
that argument is allowed too.
